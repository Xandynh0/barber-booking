# barber-booking

Sistema de agendamento para uma barbearia: página pública de reservas e painel administrativo.

Stack planejada: React (JavaScript), Laravel (PHP), MySQL, Docker e testes automatizados.

## Status

Etapa 1 (planejamento) concluída. Veja o documento completo em [`docs/planejamento-barbearia-mvp.md`](docs/planejamento-barbearia-mvp.md), com regras de negócio, telas, modelo de dados, diagrama ER e contrato inicial da API.
